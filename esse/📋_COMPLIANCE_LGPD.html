Termos, Privacidade e Conformidade

1. Política de Privacidade

📋 O que coletamos?

Ao usar MEB, coletamos:

  • Dados pessoais: Nome, email, telefone, data de nascimento
  • Dados de saúde: Peso, altura, histórico nutricional, restrições alimentares
  • Fotos de evolução: Para acompanhamento visual do progresso
  • Dados de uso: Quando você acessa, quais funcionalidades usa
  • Dados de pagamento: Se aplicável (cartão não é armazenado)

🎯 Por quê?

  • ✅ Oferecer serviços de nutrição personalizados
  • ✅ Acompanhar seu progresso
  • ✅ Enviar notificações e lembretes
  • ✅ Melhorar a qualidade do app
  • ✅ Cumprir obrigações legais (LGPD, CFN)

🛡️ Como protegemos?

  • ✅ Criptografia 256-bit em trânsito (HTTPS)
  • ✅ Criptografia em repouso (Supabase)
  • ✅ Senhas com hash bcrypt
  • ✅ Backups automáticos diários
  • ✅ Row Level Security — você vê só seus dados

📤 Compartilhamos com quem?

APENAS com:

  • ✅ Você mesma (você é dona dos seus dados)
  • ✅ Seus dados de saúde para seu profissional (você escolhe compartilhar)
  • ✅ Provedores técnicos essenciais (Supabase, Resend)
⚠️ Nunca vendemos seus dados para terceiros, anunciantes ou qualquer outra pessoa.

⏰ Por quanto tempo guardamos?

  • ✅ Enquanto você usa o app — dados ativos
  • ✅ 90 dias após deletar conta — backups
  • ✅ 1 ano para logs — segurança

2. Consentimento — LGPD

✅ Você controla tudo!

Marque apenas o que você concorda. Você pode mudar de ideia quando quiser nas Configurações.

Opcionais (você escolhe):

✅ Você pode mudar essas opções quando quiser em Configurações → Privacidade

3. Seus Direitos LGPD

Você tem direito a:

🔍 Direito de Acesso

Você pode ver TODOS seus dados quando quiser.

Em: Configurações → Meus Dados → Exportar

Formatos: PDF, CSV ou JSON

✏️ Direito de Correção

Você pode corrigir qualquer informação errada.

Basta editar em seu Perfil → Dados Pessoais

🗑️ Direito de Deleção ("Direito ao Esquecimento")

Você pode pedir para deletar sua conta e TODOS seus dados.

Em: Configurações → Conta → Deletar Permanentemente

⚠️ Aviso: Isso é irreversível. Seus dados serão apagados em até 90 dias.

📦 Direito de Portabilidade

Você pode baixar uma cópia de TODOS seus dados em formato aberto.

Em: Configurações → Exportar Dados

Você pode levar para outro app ou profissional.

🚫 Direito de Oposição

Você pode se opor ao uso de seus dados para marketing ou análise.

Em: Configurações → Privacidade → Recusas

💡 Dica: Todos esses direitos podem ser exercidos respondendo um email para contato@nutricionistameb.com.br

⏱️ Prazos

  • ✅ Você receberá resposta em até 15 dias úteis
  • ✅ Se for complexo, até 30 dias úteis
  • ✅ Totalmente GRATUITO

4. Como Protegemos Seus Dados

🔒 Criptografia em Trânsito

Quando você se conecta ao app:

  • ✅ Protocolo HTTPS/TLS 1.3 — padrão de banco
  • ✅ Certificado SSL de 256-bit
  • ✅ Seu navegador negocia chave única para sua sessão
  • ✅ Ninguém consegue interceptar sua comunicação

💾 Criptografia em Repouso

Quando seus dados estão armazenados:

  • ✅ Banco de dados Supabase — criptografia automática
  • ✅ Senhas — nunca são salvas em texto plano, apenas hash bcrypt
  • ✅ Fotos de evolução — criptografadas no Storage
  • ✅ Backups — também criptografados

🔐 Senhas

Sua senha:

  • ✅ Nunca é vista por ninguém (nem por nós!)
  • ✅ É transformada em hash com algorithm bcrypt
  • ✅ Se banco vazar, senhas não servem
  • ✅ Você pode resetar sem nos contar a senha antiga

🔄 Backups

Seus dados têm backup automático:

  • ✅ Diário — backup automático todo dia 03:00 AM
  • ✅ Semanal — 4 semanas de histórico
  • ✅ Mensal — 12 meses de histórico
  • ✅ Tudo criptografado — sem exceção

👤 Row Level Security (RLS)

Seu acesso é controlado:

  • ✅ Você vê APENAS seus dados
  • ✅ Você vê APENAS cardápios atribuídos a você
  • ✅ Você vê APENAS suas notificações
  • ✅ Não é possível hackear para ver dados alheios (implementado no DB)
✅ Certificação: MEB atende padrões OWASP Top 10 e NIST Cybersecurity Framework

5. Logs de Acesso

📊 Que tipo de log guardamos?

  • Quem — seu email/usuário
  • Quando — data e hora exata (timezone)
  • De onde — IP, navegador, dispositivo
  • O quê — qual página/ação acessou
  • Resultado — sucesso (✅) ou erro (❌)
💡 Exemplo de log:
maria@email.com | 24/06/2026 14:32:45 | Firefox/Windows | /dashboard | ✅ Success
maria@email.com | 24/06/2026 14:35:12 | Firefox/Windows | /cardapios/criar | ✅ Created

🎯 Para quê?

  • ✅ Segurança — detectar acessos suspeitos
  • ✅ Conformidade — comprovar acesso legítimo
  • ✅ Suporte — resolver problemas seus
  • ✅ Auditoria — compliance LGPD

⏰ Por quanto tempo?

1 ano — depois são deletados automaticamente

📋 Posso ver meus logs?

Sim! Em: Configurações → Segurança → Atividade Recente

Você vê os últimos 30 dias de acessos seus.

🚨 Detectamos acesso suspeito

Se detectarmos algo estranho, nós:

  • ✅ Enviamos email alertando
  • ✅ Pedimos confirmação de novo login
  • ✅ Você pode revogar sessões antigas
